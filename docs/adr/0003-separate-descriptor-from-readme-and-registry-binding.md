# Separate the Descriptor from README and Registry Binding

> Partially superseded by ADR-0004: Git remotes and Registry locations remain outside the portable Descriptor; no later portable Registry Binding is added.

SKIT stores its portable machine-owned Descriptor in `skit.json` and treats `README.md` as human-owned documentation. A Descriptor can be unbound, using a local slug and explicit Skill membership without asserting a Registry Namespace or canonical Registry identity; publication declarations may remain incomplete while unbound, and a later authorized binding records Registry identity separately. Optional `sameAs` fields express portable identity claims for the Skill Collection and its attributed author, but do not prove control or grant authorization. We rejected README YAML frontmatter because initialization could not safely adopt repositories with existing documentation, and rejected a required `<namespace>/<slug>` at initialization because it made a local action assert unverified remote authority. A future `$schema` property is preferred over a redundant version field, but generation must omit it until a canonical HTTPS schema or published package-local schema exists.
